# СтудПортал ИРИТ-РТФ

## О проекте

Сервис предназначен для объединения студенческих организаций университета в единую экосистему. 
Портал позволяет студентам находить клубы по интересам, подавать заявки на вступление и отслеживать их статус, 
а руководителям организаций — публиковать новости, создавать мероприятия и управлять составом. 
Для администрации предусмотрена отдельная панель управления пользователями и организациями.

## Стек технологий

- **Бэкенд:** Python 3.12, FastAPI, SQLAlchemy, SQLite
- **Фронтенд:** React 18, Vite, Bootstrap 5 (кастомная тема в стиле соцсети)
- **Аутентификация:** JWT (JSON Web Tokens), разграничение прав (Студент / Руководитель / Администрация)
- **Хранение файлов:** локальное хранилище (загрузка аватарок, обложек и фото для новостей)
- **Тестирование:** Pytest, HTTPX (автотесты ключевых сценариев)
- **Документация API:** Swagger (`/docs`)

## Реализованный функционал

- **Каталог:** поиск по названию и описанию, фильтрация по 4 параметрам (направление, формат, факультет, размер).
- **Страница организации (ВК-стиль):**
  - Красивая обложка и аватарка организации.
  - Центральная лента новостей с полноценными постами (текст + фото).
  - Правая панель: список событий (с возможностью записи) и сворачиваемые отзывы.
- **Профиль кандидата:** студент заполняет профиль (ФИО, группа, О себе, портфолио) один раз, данные автоматически прикрепляются к заявкам.
- **Заявки:** подача с анкетой, управление приоритетом (как при поступлении в вуз) и отзыв заявки (удаление).
- **Личный кабинет:** список заявок со статусами, членства, уведомления, редактирование профиля.
- **Интерфейс руководителя:**
  - Редактирование страницы организации (загрузка аватарки и обложки с ПК, изменение описания).
  - Создание новостей (с загрузкой фото) и мероприятий (событий).
  - Дашборд с цифрами отчётности.
  - Управление входящими заявками (перевод по статусам) и назначение должностей участникам.
- **Панель администратора:**
  - Просмотр всех пользователей с поиском по ФИО/Email и фильтром по ролям.
  - Назначение ролей и удаление пользователей.
  - Просмотр всех организаций, поиск и удаление.
- **Адаптивность:** корректное отображение на десктопах и мобильных устройствах.
- **Валидация:** строгая проверка форм на клиенте и сервере (нельзя отправить пустые данные).

## Структура проекта

- `backend/` — серверная часть (модели, роутеры, сид демо-данных, тесты)
- `frontend/` — клиентская часть (React-компоненты, страницы, API-клиент)
- `docs/` — схема базы данных


## Запуск проекта

### 1. Бэкенд

Перейдите в папку `backend`, создайте виртуальное окружение и установите зависимости:

```
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
Заполните базу демонстрационными данными (выполняется один раз):


python -m app.seed
Запустите сервер:

uvicorn app.main:app --reload
API доступно по адресу: http://localhost:8000

Документация Swagger: http://localhost:8000/docs
```

### 2. Фронтенд
Откройте второй терминал, перейдите в папку frontend и установите зависимости:

```
cd frontend
npm install
Запустите dev-сервер:


npm run dev
Приложение доступно по адресу: http://localhost:5173
```
Тестирование

2. авторизацию и полный сценарий: создание организации → подача заявки → согласование → добавление в участники.
