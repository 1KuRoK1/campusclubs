# СтудПортал ИРИТ-РТФ

Портал управления студенческими организациями. 
Разработан в рамках проектного практикума (роль: Разработчик).

## О проекте

Сервис предназначен для объединения студенческих организаций университета в единую экосистему. 
Портал позволяет студентам находить клубы по интересам, подавать заявки на вступление и отслеживать их статус, 
а руководителям организаций — управлять входящими заявками и составом.

## Стек технологий

- **Бэкенд:** Python 3.12, FastAPI, SQLAlchemy, SQLite
- **Фронтенд:** React 18, Vite, Bootstrap 5 (кастомная тема)
- **Аутентификация:** JWT (JSON Web Tokens), разграничение прав по ролям
- **Документация API:** Swagger (встроен в FastAPI)

## Реализованный функционал

- **Каталог организаций:** поиск по названию и описанию, фильтрация по направлению, формату, факультету и размеру.
- **Страница организации:** описание, контакты, рейтинг, отзывы участников.
- **Подача заявок:** анкета кандидата, прикрепление ссылки на портфолио.
- **Приоритеты заявок:** возможность выстраивать приоритет поданных заявок (как при поступлении в вуз).
- **Личный кабинет:** список заявок со статусами, членства в организациях, уведомления.
- **Интерфейс руководителя:** просмотр входящих заявок в свои организации и смена их статусов (Подана → Рассмотрение → Собеседование → Решение).
- **Адаптивность:** корректное отображение на десктопах и мобильных устройствах.

## Структура проекта

- `backend/` — серверная часть (модели, схемы, роутеры, сид демо-данных)
- `frontend/` — клиентская часть (React-компоненты, страницы, API-клиент)
- `docs/` — схема базы данных

## Запуск проекта

### 1. Бэкенд

Перейдите в папку `backend`, создайте виртуальное окружение и установите зависимости:

```
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
Заполните базу демонстрационными данными (выполняется один раз):


python -m app.seed
Запустите сервер:

uvicorn app.main:app --reload
API доступно по адресу: http://localhost:8000

Документация Swagger: http://localhost:8000/docs
```

### 2. Фронтенд
Откройте второй терминал, перейдите в папку frontend и установите зависимости:

```
cd frontend
npm install
Запустите dev-сервер:


npm run dev
Приложение доступно по адресу: http://localhost:5173
```

Ключевой сценарий
* Авторизуйтесь под студентом.
* В каталоге найдите интересующую организацию и откройте её страницу.

* В личном кабинете настройте приоритет заявки.

* Вернитесь в аккаунт студента и проверьте обновлённый статус и уведомление.
