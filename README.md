# СтудПортал ИРИТ-РТФ

Портал управления студенческими организациями. 
Разработан в рамках проектного практикума (роль: Разработчик).

## О проекте

Сервис предназначен для объединения студенческих организаций университета в единую экосистему. 
Портал позволяет студентам находить клубы по интересам, подавать заявки на вступление и отслеживать их статус, 
а руководителям организаций — управлять входящими заявками, создавать мероприятия и вести отчётность.

## Стек технологий

- **Бэкенд:** Python 3.12, FastAPI, SQLAlchemy, SQLite
- **Фронтенд:** React 18, Vite, Bootstrap 5 (кастомная тема ИРИТ-РТФ)
- **Аутентификация:** JWT (JSON Web Tokens), разграничение прав по ролям
- **Документация API:** Swagger (встроен в FastAPI)
- **Тестирование:** Pytest, HTTPX (автотесты ключевых сценариев)

## Реализованный функционал

- **Каталог организаций:** поиск по названию и описанию, фильтрация по направлению, формату, факультету и размеру.
- **Страница организации:** описание, контакты, рейтинг, отзывы (с формой добавления), афиша мероприятий (с записью).
- **Профиль кандидата:** студент заполняет профиль (ФИО, группа, О себе, ссылка на портфолио) один раз, и эти данные автоматически прикрепляются к его заявкам.
- **Подача заявок:** с возможностью управления приоритетом (стрелками вверх/вниз) и отзыва заявки (удаления до одобрения).
- **Личный кабинет:** список заявок со статусами, членства в организациях, уведомления, настройки профиля.
- **Интерфейс руководителя:** создание организации, дашборд с цифрами отчётности (участники, мероприятия, документы), управление входящими заявками (перевод по статусам), назначение должностей участникам.
- **Адаптивность:** корректное отображение на десктопах и мобильных устройствах.
- **Валидация:** строгая проверка данных на клиенте и сервере (нельзя отправить пустые формы).

## Структура проекта

- `backend/` — серверная часть (модели, роутеры, сид демо-данных, тесты)
- `frontend/` — клиентская часть (React-компоненты, страницы, API-клиент)
- `docs/` — схема базы данных и скриншоты

## Запуск проекта

### 1. Бэкенд

Перейдите в папку `backend`, создайте виртуальное окружение и установите зависимости:

```
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
Заполните базу демонстрационными данными (выполняется один раз):


python -m app.seed
Запустите сервер:

uvicorn app.main:app --reload
API доступно по адресу: http://localhost:8000

Документация Swagger: http://localhost:8000/docs
```

### 2. Фронтенд
Откройте второй терминал, перейдите в папку frontend и установите зависимости:

```
cd frontend
npm install
Запустите dev-сервер:


npm run dev
Приложение доступно по адресу: http://localhost:5173
```
